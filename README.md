# 감정관실 실무 도구

국가유산청 문화유산감정관실의 현장 실무를 위한 웹 도구 모음입니다. 감정 대상물의 **판별**, 도난 국가유산 목록과의 **대조**, 외국인 신청인 **안내**, 검색대 적발 시의 **절차** 확인을 네 개의 도구로 나누어 다룹니다.

**바로가기 → https://pudgala-appraiser.github.io/appraisal-office-toolkit/**

모든 도구는 설치 없이 브라우저에서 실행되며, 휴대폰에서도 그대로 사용할 수 있습니다.

### 審 · 문화유산 감정

사진(전체·세부·명문·저부 등 최대 6장)과 증빙 정보를 등록하면 시행령 [별표 3]의 판단 기준 체계에 따라 소견을 제시합니다. 판별 결과는 세 가지입니다.

- 일반동산문화유산 해당 (반출 불가)
- 비문화유산 (반출 가능)
- 판정 보류 (실물 정밀 감정 필요)

판별과 별도로, 법 제60조제5항의 확인 의무를 전제한 **처리 경로**를 함께 권고합니다. 비문화유산이라도 외형상 오인될 여지가 남으면 실물 지참 확인을 권고하고, 구입 영수증·상품 라벨·작가 서명 등으로 오인 우려가 해소되면 사전예약감정(훈령 제9조제6항)이 적합함을 안내합니다. 명백한 사안과 실물 확인이 필요한 사안을 창구 이전 단계에서 갈라내기 위한 기능입니다.

## 유의사항

본 도구들은 감정위원의 판단을 **보조**하며, 감정의 최종 판단은 감정위원이 합니다. 특히 감정 도구의 소견은 화상 자료에 근거한 참고용으로, 시행규칙 제45조에 따른 공동 감정과 실물 확인을 대체하지 않습니다.

도난국가유산 검색기의 결과 역시 1차 검토 후보이며, 확인은 국가유산청 공식 정보로 하셔야 합니다.

법령·훈령은 개정될 수 있습니다. 각 도구에 반영된 기준의 최신 여부는 국가법령정보센터에서 확인하시기 바랍니다.
